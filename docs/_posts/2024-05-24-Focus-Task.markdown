# Detect & Reach

Here's a browser-based implementation of a change detection task with a challenging motor report using [JSPsych](https://www.jspsych.org/). We designed this task to study how reward and difficulty impact perceptual decision making and motor control. 

You can perform the task here: [Detect & Reach Task](https://adithyanarayan101.github.io/jsFocus)
